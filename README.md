# Fraud Strategy Simulator
Backtesting rules, gradient boosting and neural network strategies for account-opening fraud on 1M applications.

This project aims to answer the following questions:
- How much do network-style features (velocity, shared devices) contribute to detection?
- Which strategy catches the most fraud at a fixed decline rate: rules, model, or hybrid?
- Which customer segments does the model serve worst?

## Data
The dataset used is present here: [Bank Account Fraud Dataset Suite (NeurIPS 2022)](https://www.kaggle.com/datasets/sgpjesus/bank-account-fraud-dataset-neurips-2022). It comprises a total of 6 different synthetic bank account fraud tabular datasets. This project requires the 'Base.csv' data. The dataset isn't present on the repo. Users can download the Base csv file and place it in '/data/raw' folder to work through it.
